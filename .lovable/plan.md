# تنفيذ مسار القصة النهائي

## النتيجة
- يبدأ إنشاء خمس صور تلقائيًا داخل نفس عملية إنشاء القصة الناجحة، دون الاعتماد على فتح شاشة العرض أو زر Illustrate.
- تحفظ الصور وتُعاد قراءتها عند التحديث وإعادة الفتح.
- لا يُنشأ PDF قبل جاهزية الصور الخمس، ويستخدم الصور المحفوظة فقط.
- يبقى الصوت النسائي الحالي دون تغيير.

## التنفيذ
1. نقل بدء الصور من مؤقت شاشة العرض إلى مرحلة ما بعد اكتمال إنشاء القصة مباشرة، مع مفتاح ثابت للقصة.
2. استخدام الحماية الحالية للصفحات المكتملة، وإضافة حجز ذري للخصم يمنع تكراره عند التحديث أو إعادة المحاولة المتزامنة.
3. إعادة الصور المحفوظة مع نتيجة القصة، والإبقاء على الاستعادة اليدوية للصفحات المفقودة فقط.
4. منع تصدير PDF للقصة حتى تكون كل صفحاتها مرتبطة بصور محفوظة، وعدم استخدام ملف PDF نصي قديم.
5. إضافة اختبارات مركزة، نشر الوظائف المطلوبة، ثم التحقق من المسار المنشور.

## حدود التغيير
- لا تغيير في Backend Core أو VPS أو الأسعار أو حدود الخطة أو نظام الصوت.
- لا جدول أرصدة جديد ولا إعادة تصميم للواجهة.

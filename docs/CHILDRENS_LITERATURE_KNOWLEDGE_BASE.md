## 1. Core Authoring Principles (Part 1 — "From Idea to Message")

### 1.1 Children's lit ≠ adult lit
| Children | Adults |
|---|---|
| Sentences 5–10 words | Compound, long |
| Simple, familiar vocabulary | Rich, varied |
| Fast, rising rhythm | Slow allowed |
| Image is part of meaning | Image is decoration |
| Inner, simple conflict | Multi-layered |
| Ending = always hope | May be open/tragic |
| Hero is reader's age | Any age |

### 1.2 The "1-meter-tall" rule
Write from the child's POV — eye-level, fears, wonder, scale.

### 1.3 The Four Axes
1. **Simplicity & Clarity** — shortest word that carries meaning. 1 sentence = 1 idea. Paragraphs ≤ 3 sentences for under-10.
2. **Visual Balance** — text and illustration each carry half the meaning. Never restate in text what the picture shows.
3. **One Message** — every story carries exactly one core SEL/values message.
4. **Emotional Truth** — feelings are validated, never shamed.

### 1.4 The Five Story Elements
Hero · Goal · Obstacle · Climax · Resolution.

### 1.5 Stakes (Part 1 Unit 5)
Internal stakes (belonging, dignity, safety) > external stakes for ages 3–8. Escalate via "Yes-but / No-and" attempt ladder.

## 2. Character & Plot Engineering (Part 2)

### 2.1 SPEC technique (character spec)
- **S** = Sense (visual signature: clothing, color, accessory)
- **P** = Problem (the inner flaw / emotional challenge)
- **E** = Engine (motivation, what they want)
- **C** = Charm (likable quirk)

### 2.2 The Magic of the Flaw
The hero MUST have one visible flaw the child can recognize in themselves. Perfection kills empathy.

### 2.3 Supporting Cast
- **Mentor** (safe-base figure — parent, teacher, elder, even pet)
- **Companion** (peer-level)
- **Challenger** (NEVER pure villain for under-8 — a misunderstood obstacle)

### 2.4 4-Act Structure
1. Normal world (1–2 pages)
2. Disturbance / inner feeling appears (2–3 pages)
3. Attempt ladder — Yes-but, No-and (4–6 pages)
4. Turn + safe resolution (2–3 pages)

### 2.5 Dramatic Pacing
Escalate emotion, not violence. Every page should end with a soft hook that pulls the next page-turn.

### 2.6 Dialogue rules
- Short lines, one beat each
- Voice = character's flaw audible
- No adult moralizing voice

### 2.7 First & Last Sentence
First sentence = sensory hook. Last sentence = peaceful echo of the message — never a stated moral.

## 3. Scientific Specifications (Part 3-A)

### 3.1 Psychological Foundations (5 pillars)
| Theory | Authoring Implication |
|---|---|
| **Bowlby — Attachment** | Provide a safe base; guarantee hopeful ending so child can safely feel fear |
| **Piaget — Cognitive stages** | Vocabulary & abstraction match age band exactly |
| **Vygotsky — ZPD** | Challenge slightly above current level — solvable with small effort |
| **LeDoux — Emotional memory** | Bind the message to a real felt emotion → it sticks |
| **Seligman — Positive psychology** | Hero fails then succeeds → teaches resilience, not perfection |

### 3.2 Piaget Age Bands (canonical for the engine)
| Age | Stage | Writing rules |
|---|---|---|
| 0–2 | Sensorimotor | Big images, rhythmic micro-text, vivid clear color |
| 2–7 | Pre-operational | Characters express feelings explicitly. Simple direct conflict. Happy ending mandatory |
| 7–11 | Concrete operational | More complex conflict, world-building, logical problem solving |
| 11+ | Formal operational | Social issues, moral dilemmas, identity questions |

### 3.3 Goleman EQ skills (must include ≥1 per story)
Self-awareness · Emotional regulation · Motivation · Empathy · Social awareness.

### 3.4 Bibliotherapy Arc (4 stages — every story)
1. **Identification** — child recognizes self in hero
2. **Catharsis** — feels the emotion safely
3. **Insight** — sees a way through
4. **Universalization** — "I am not alone"

### 3.5 Neuroscience hormones
| Hormone | Triggered by | Use |
|---|---|---|
| Dopamine | Surprise + small reward | Page-turn hook |
| Oxytocin | Warm relational moments | Mentor/companion scenes |
| Cortisol | Threat | Use sparingly, always resolved |
| Serotonin | Resolution + safety | Closing pages |

### 3.6 Attention span (cognitive load)
- Age 3–5: ≤ 2 narrative units / page · 8–10 min total
- Age 6–8: ≤ 3 units / page · 15–20 min total
- Age 9–12: ≤ 4 units / page · 25–30 min total

### 3.7 IBBY + UNESCO criteria (6)
1. Literary quality
2. Visual quality
3. Cultural authenticity
4. Inclusivity (gender, ability, ethnicity)
5. Hopeful worldview
6. No exploitation, no tracking of child data

### 3.8 Banned content (Trauma-Informed)
- Shame parenting · hopeless endings · gratuitous fear · stereotypes · preachy morals · emotion invalidation · adults always being saviors · linking guilt to identity · mocking mistakes.

## 4. SEL Story Design Framework (Practice Workbook)

### 4.1 Targeted Feelings (catalog)
Anger · Jealousy · Shyness · Fear · Sadness · Rejection · (extend: frustration, embarrassment, loneliness, pride, gratitude, courage).

### 4.2 SEL Outcome Statement (mandatory contract)
> "After reading, the child will be able to **[skill]** when feeling **[emotion]**."

Every generated story MUST persist this exact field.

### 4.3 Product Tier Logic (informs monetization)
| Tier | Contents |
|---|---|
| Core | Story PDF only |
| +Activity | Story + worksheet + practical tool |
| Bundle | Story + activities + Parent Guide |

Parent Guide alone justifies 2–3× pricing.

### 4.4 Quality Rubric (1–5 each, total /25; below 18 = regenerate)
1. Clarity of SEL skill
2. Age-appropriateness (Piaget)
3. Emotional safety (Trauma-Informed)
4. Indirect message (no preaching)
5. Practical tool included

### 4.5 Visual color-emotion map (illustration agent)
- Anger → warm red/orange
- Sadness → deep blue
- Calm/safety → soft green / light blue
- Joy → yellow / warm pastel
- Fear → muted purple / shadow tones (resolved to warm by end)

### 4.6 Character Visual Consistency Hash
Every story locks: `{ clothing, palette, accessory, face_shape }` — injected into every page's illustration prompt to keep the hero recognizable across all pages.

## 5. Production & Publishing (Part 3-B)

### 5.1 Golden length: **10–15 pages** per picture book
- 1 idea per page · 1–2 sentences per page · soft hook on page-end.

### 5.2 Output formats (entitlement matrix)
| Format | Use |
|---|---|
| Printable PDF | Home reading, gifting |
| Interactive web reader | Default app experience |
| Audiobook (ElevenLabs) | Premium / bedtime |
| Slideshow (projector) | Schools / classrooms |

### 5.3 Revenue streams from one story
Direct sale · Bundle (story + activity + parent guide) · Audiobook · Print-on-Demand · School license · Subscription library.

### 5.4 Brand consistency
Fixed visual identity · fixed message tone (warm, calming, never fear-marketing) · age-banded series (one feeling per story, build catalog by emotion).

## 7. Voice & Tone Bank (microcopy guide)

- Bedtime calm, never shouty.
- Validate first, instruct second: "It's okay to feel… and here's something we can try."
- Never use "must / should / have to" with children. Prefer "can / let's try / maybe".
- End every story with a peaceful sensory image (warm light, slow breath, soft sound).

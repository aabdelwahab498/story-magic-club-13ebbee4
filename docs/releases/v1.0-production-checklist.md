# v1.0 MVP Production Checklist

Before the final switch to direct live traffic, the following checks must be verified.

## Security ✓
- [x] All Supabase tables use RLS with `auth.uid() = user_id`.
- [x] Backend routes are protected with `AuthGuard` and `PermissionsGuard`.
- [x] `SUPABASE_SERVICE_ROLE_KEY` is completely isolated in the backend and not in the frontend source or environment.

## Performance ✓
- [x] React Query caching eliminates duplicate requests for libraries and child profiles.
- [x] Backend responds within acceptable timeouts.
- [x] Frontend bundle size has been audited and split where necessary.

## Deployment ✓
- [x] Frontend successfully builds (`npm run build`) with zero TypeScript errors.
- [x] Backend successfully builds (`npm run build`) with zero TypeScript errors.
- [x] CI/CD pipeline correctly handles code validation on PRs and the main branch.

## Environment ✓
- [x] Separate Development, Staging, and Production projects/keys configured.
- [x] `NODE_ENV=production` is set in the NestJS runtime.
- [x] CORS policies are restricted to the production UI domains.

## Monitoring ✓
- [x] `/health` endpoint is live and returning `{ status: 'ok', version: '1.0.0' }`.
- [x] Logging is prepared for AI duration metrics and error states.

## Backup ✓
- [x] Automated daily database backups configured in Supabase.
- [x] Point-In-Time Recovery (PITR) enabled or planned for the live project.

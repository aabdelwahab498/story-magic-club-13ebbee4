# Git Release Notes (git-release-notes.md)

This note catalogs version tags and milestones for Najmah v1.0.0.

---

## 1. Release Identification
* **Git Tag:** `v1.0.0`
* **Release Branch:** `main`
* **Prerequisites:** Successful CI linting and compiler checks.

---

## 2. Milestone History
1. **Milestone 1:** Migration of edge functions to NestJS API gateway, ensuring unified security policies.
2. **Milestone 2:** Dockerizing NestJS and FastAPI services for container-based deployments.
3. **Milestone 3:** Observability setup with Pino JSON logging and Prometheus telemetry.
4. **Milestone 4:** Performance optimizations reducing query latency (~77%) and bundle sizes (~74%).
5. **Milestone 5:** Job Abstraction and Startup Diagnostics setup to prepare for horizontal scaling.

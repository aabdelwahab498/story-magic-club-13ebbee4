# Product Overview (product-overview.md)

Najmah is a next-generation AI-powered story creation platform designed for children, parents, and educators. It integrates creative storytelling, emotional growth frameworks, and high-fidelity media assets into a single platform.

---

## 1. Core Value Proposition
* **Social-Emotional Learning (SEL):** Every story is built around an SEL outcome, helping children develop qualities like courage, kindness, empathy, and resilience.
* **Child-Centric Tailoring:** Generation parameters are customized to the child's age, vocabulary, and reading level to ensure age-appropriate narratives.
* **Rich Multimodal Experience:** Text prose is accompanied by custom illustrations and text-to-speech narrations to engage young readers.

---

## 2. Main Capabilities
* **Interactive Storyteller:** Generates custom stories in multiple languages (English, Arabic, French, Spanish, German, Italian) with high-fidelity RTL text formatting.
* **Scene Illustrations:** Renders high-quality scene backdrops and characters matching description constraints.
* **Stitched Narrations:** Edge TTS engines narrate page text in natural-sounding, age-appropriate voices.

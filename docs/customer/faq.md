# Technical Frequently Asked Questions (FAQ) — Najmah AI Platform

This document answers common architectural, operational, and expansion questions regarding the **Najmah AI Platform**.

---

## 1. System Architecture

### Q: What is the high-level architecture of Najmah?
**A:** Najmah is a decoupled microservice platform consisting of three primary layers:
1. **React SPA Frontend:** Renders UI, handles client localization, font scaling, and PWA offline precaching.
2. **NestJS API Monolith Gateway:** Manages authentication, RBAC authorization, credit limits, usage tracking, and Export Center execution.
3. **Python FastAPI AI Microservice:** Dedicated LLM pipeline handling 4-act story planning, writer composition, quality validation scoring, and retry loops.

### Q: Why use NestJS for the Backend Gateway?
**A:** NestJS provides an enterprise TypeScript architecture with built-in dependency injection, modular domain isolation, robust middleware guards, and strict validation decorators (`class-validator`), ensuring high maintainability and security.

### Q: Why use FastAPI for the AI Microservice?
**A:** FastAPI is asynchronous, lightweight, and native to the Python ecosystem, enabling seamless integration with AI/LLM SDKs (Google Gemini, OpenAI, PyTorch) and Pydantic schema validation.

## 2. AI Storytelling & SEL Engine

### Q: How does the AI story generation pipeline work?
**A:** Story generation follows a deterministic 4-step pipeline:
1. **Planner:** Generates a 4-act blueprint (Hero intro, Mentor interaction, Companion challenge, SEL outcome).
2. **Writer:** Writes localized story prose tailored to the target age group.
3. **Safety & Quality Check:** Evaluates safety policies and scores story prose against quality metrics (minimum threshold `>=18/25`).
4. **Regeneration Loop:** Up to 2 retries are attempted if safety or quality score fails before returning an error.

### Q: How do I add or swap AI/LLM Providers?
**A:** In `ai-service`, AI providers inherit from `BaseLlmProvider` (`app/providers/base.py`). To add a new provider (e.g. Anthropic Claude or OpenAI GPT-4o):
1. Implement a new class in `app/providers/` implementing `generate_story_plan` and `write_story_content`.
2. Register the provider in `app/agents/factory.py`.

## 3. Database & Data Backups

### Q: How are tenant data and user files secured?
**A:** Data security is enforced at two levels:
* **Row-Level Security (RLS):** All PostgreSQL tables enforce RLS policies restricting data reads/writes strictly to the authenticated owner (`auth.uid() = user_id`) or admin roles.
* **Storage Signed URLs:** Exported PDFs and ZIP bundles are served via temporary 24-hour signed URLs generated by Supabase S3 storage APIs.

### Q: How do I perform database backups?
**A:** PostgreSQL database instances should be backed up using standard pg_dump or automated Supabase WAL backups:

```bash
pg_dump -h xyz.supabase.co -U postgres -d postgres -F c -b -v -f najmah_backup_$(date +%Y%m%d).dump
```
